# terraform-aws-jaws-foundation

Terraform modules for an AWS account's foundation: naming and tagging context, the Terraform state bucket, private buckets, service-linked roles and IAM Identity Center access

The modules are on their way: this is the initial scaffold. Once the first
version is released they are published on the
[Terraform Registry](https://registry.terraform.io/modules/jwallace145/jaws-foundation/aws/latest)
as `jwallace145/jaws-foundation/aws`.
